# Archived evaluation documents

**Everything in this directory is superseded. Do not treat any of it as current.**

These are earlier evaluation frameworks and protocols, kept because they record how the
measurement design changed and why. They describe methods that were replaced, thresholds that
were recalibrated, and in some cases conclusions that later measurement overturned.

If you are looking for how evaluation works now, read `docs/eval/` one level up, and the
`Research` section of the README.

Nothing here is maintained. Numbers in these files were correct when written and have not been
re-checked since. Do not cite them.

## Why these are still in the repository

Git already holds every deleted file, so keeping superseded documents in the working tree is a
deliberate choice rather than an accident of history. The reason is that this project's
documented failure mode is a stale claim outliving the measurement that produced it, and a
reader who finds an old framework and cannot see what replaced it is exactly that failure. The
directory exists so the replacement is visible next to the thing it replaced.

That only works if this notice is here. If you add a file to this directory, it is superseded by
definition. Say what superseded it.
